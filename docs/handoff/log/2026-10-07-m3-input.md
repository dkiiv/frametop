Done:
- Host decision: stay on stock Sunshine through M3. Curtis's requirement recorded in
  04-milestones (M4): multiple *virtual* displays, not only mirrors of physical monitors;
  switch to Vibepollo (built-in per-client virtual displays, "Remote Monitor") at the start
  of M4.
- Removed the PC's standalone MikeTheTech "Virtual Display Driver" (v11.30.4.434):
  `pnputil /export-driver` backup into the user's Documents\driver-backup, then
  `pnputil /remove-device ROOT\DISPLAY\0000` + `/delete-driver ... /uninstall` (one UAC prompt).
  Neither virtual display was an active screen, so the desktop layout didn't change. Left
  "Virtual Desktop Monitor" alone (Virtual Desktop Streamer, installed, uses it). To re-add the
  VDD later, use its official installer (it also creates the root device), or Vibepollo's own.
- ftrd-stream input:
  - Panel: `VROverlayInputMethod_Mouse`, mouse scale = stream size (5120x1440),
    `SendVRDiscreteScrollEvents`, `MakeOverlaysInteractiveIfVisible` (controllers work with the
    dashboard closed; NOTE this takes controllers from a VR game; M5 must turn it off then).
  - Laser move -> `LiSendMousePositionEvent` (GL bottom-left origin flipped); left/right/middle
    -> `LiSendMouseButtonEvent`; discrete scroll -> `LiSendScrollEvent`/`LiSendHScrollEvent`
    (SteamVR's positive = up = Moonlight's positive); FocusLeave and exit release held buttons.
  - Keyboard button (0.14 m procedurally drawn overlay under the panel's bottom-right) toggles
    SteamVR's keyboard (`ShowKeyboardForOverlay`, Minimal + ShowArrowKeys). Characters ->
    `LiSendUtf8TextEvent`; control bytes -> VK keys via `LiSendKeyboardEvent(0x8000|VK)`:
    08/7f Backspace, 0a/0d Enter, 09 Tab, 1b Esc, ESC[A-D arrows. Only control bytes are logged
    (hex), never typed text.
  - Default stream rate now **90 fps** (headset rate); Sunshine accepts it (PC monitor is 240 Hz).
  - `--input-test` flag: moves the PC cursor to (1234, 567) 3 s in, for headless checks.
