# 2026-10-07 — PC link: heartbeat, monitor arrangement, physical-monitor fail-safe (observe mode tested)

Curtis's requirements (2026-10-07):
1. While the Frame shows virtual monitors, the PC's physical monitors go "disconnected", so every
   window is reachable from the Frame.
2. A Windows-side runtime listens for a heartbeat that the Frame sends only while one of its
   virtual monitors is open; without it, Windows takes the physical displays back and turns the
   virtual ones off (the PC must never be left unusable if the Frame disconnects/crashes/exits).
3. The Frame sends how its virtual screens sit relative to each other, and Windows arranges its
   monitors the same way (left panel = left monitor), so dragging windows across is natural.
4. Coordinate the first real test of the physical disconnect with Curtis.

Done:
- remote-display/host/ftrd-host.ps1 (Windows agent; README there) and
  remote-display/stream/ftrd-presence.py (Frame responder, started by stream.sh). The PC pings
  the Frame (outbound UDP 47810, so no Windows firewall rule or admin needed); the Frame answers
  only while an instance runs; replies are HMAC-signed with a shared key over the PC's nonce.
- ftrd-stream writes its state (size, app, identity, window id, suspended) to FTRD_STATE_FILE.
- ft-floatd: `list apps` (output:ft-screens number:app) so the Frame knows which panel holds
  which monitor; panel azimuth/elevation from ft-screens "get N" and "head". Needs ft-floatd
  restarted (next desktop restart) to take effect; until then monitors are a row in instance
  order.
- Observe mode (default) replaces the earlier layout watcher: physical monitors kept at the saved
  baseline, virtual monitors arranged right of them. Control mode (physical off) is coded,
  untested, and off until Curtis and I test it together.
- Fail-safe paths: Frame silent 5 s or reporting no monitors -> physical back at the baseline
  (+ Vibepollo terminate_virtual with an optional API token); a guard process restores if the
  agent dies while armed; the agent restores at startup if it finds itself armed.
- ftrd-stream: also retries when the host says another stream operation is still running.

Measured:
- Link: Frame answered with 2 monitors (cert hash, size); the agent mapped both to Vibepollo's
  displays and arranged them right of the ultrawide (5120,0 and 6688,0) with the physical layout
  untouched.
- Frame silent (presence killed at 19:50:00): agent logged "Frame silent for 5 s" and ran the
  restore at 19:50:06-07.
